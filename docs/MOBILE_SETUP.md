# Мобильді қосымшаны Android және iPhone-да тексеру нұсқаулығы

Бұл нұсқаулық бағдарламалауды жаңа бастаған мұғалімдерге телефоннан қосымшаны қалай тексеру керектігін қарапайым тілмен түсіндіреді.

---

## ⚠️ Маңызды ескерту: «localhost» туралы түсінік

Компьютерде жұмыс істегенде сервер мекенжайы көбінесе `http://localhost:4000` болады. 

**Бірақ телефоннан қарағанда «localhost» — бұл телефонның өзі, компьютер емес!**
Сондықтан телефон компьютеріңіздегі серверді көруі үшін:

1. **Компьютер мен телефон бір Wi-Fi желісіне қосылуы керек.**
2. Компьютердің жергілікті IP мекенжайын анықтаңыз:
   - **Windows:** Командалық жолда `ipconfig` деп жазып, `IPv4 Address` жолын көріңіз (мысалы: `192.168.1.45`).
   - **macOS / Linux:** Терминалда `ip route get 1.1.1.1` немесе `ifconfig` деп жазыңыз.
3. Қосымшадағы API мекенжайын былай көрсетіңіз:
   `http://192.168.1.45:4000/api` (мұндағы 192.168.1.45 — сіздің компьютеріңіздің IP-і).

## 2-тәсіл: Expo Go арқылы iPhone мен Android-та іске қосу

1. **Телефонға Expo Go орнатыңыз:**
   - iPhone үшін: App Store арқылы **Expo Go** қосымшасын жүктеп алыңыз.
   - Android үшін: Google Play арқылы **Expo Go** қосымшасын жүктеп алыңыз.

2. **Компьютердегі терминалда мына командаларды орындаңыз:**
   ```bash
   # 1. Жобаның негізгі қалтасына кіріңіз:
   cd /home/agent/workspace/apps/mobile

   # 2. Expo серверин іске қосыңыз:
   npx expo start
   ```

3. **Телефонмен қосылу:**
   - Терминалда үлкен **QR-код** пайда болады.
   - **iPhone-да:** Телефонның қарапайым камерасын ашып, QR-кодқа бағыттаңыз -> экранда «Open in Expo Go» деген хабарлама шығады, оны басыңыз.
   - **Android-та:** Expo Go қосымшасын ашып, «Scan QR Code» батырмасын басып, QR-кодты сканерлеңіз.

4. Қосымша телефонда ашылып, нақты мобильді құрылғы ретінде жұмыс істейді!

## 3-тәсіл: Мобильді қосымшаны құрастыру (Production Build)

Егер Google Play Store (.aab / .apk) немесе Apple App Store (.ipa) үшін дайын файл жасағыңыз келсе:

```bash
# apps/mobile қалтасында:
cd apps/mobile

# Expo Application Services (EAS) құралын орнату:
npm install -g eas-cli

# EAS жүйесіне кіру (тегін аккаунт):
eas login

# Android APK файлын жасау:
eas build --platform android --profile preview

# iOS файлын жасау:
eas build --platform ios --profile preview
```
Бұлттық жүйе бірнеше минутта дайын орнату файлын береді.
